Left and right spacing for every screen. Content never touches the edge: the page keeps a gutter, and each panel keeps its own inner padding so text in different panels lines up on the same vertical line.

  • Inside a panel, every row starts at 24px: section title, fields, code and table cells.
  • Tables and code scroll inside their own box; the page itself never scrolls sideways.
  • Don't add extra margins to single elements; use gap on the parent.

Principles

Rules that decide most layout and styling questions before they come up.

01Red is for action

Heritage Red marks the one primary action per area and selected states. Never for titles, large fills or decoration.

02Two accents at most

Red for action, green for success. Everything else is warm grey and ink. Status always pairs color with an icon or text.

03Flat surfaces

Cards and panels use a 1px border, no drop shadow. Shadows are reserved for floating layers: dropdowns, modals, toasts.

04Width for the work

Wide tables and import tools get the full width: steppers go horizontal and the sidebar collapses in focus mode.

check_circleDoUse one Primary button per toolbar. Put secondary actions in Secondary or Ghost style. Write labels as verbs: Search, Add USP, Save Master.
cancelDon'tAdd a colored left border to cards, use emoji as icons, mix icon sets, or show a red title. Avoid long alert popups: use a one-line toast.

Stepper

Shows where the user is in a multi-step form. Horizontal, sticky at the top of the work area. No connector lines: each step carries its own state in the dot, the caption and a bar underneath.

HTML
<nav class="panel stepper" style="position:static;display:flex">
  <button class="step done"><span class="step-dot"><span class="ms" style="font-size:18px">check</span></span><span class="step-tx"><b>Basic Info</b><em>Completed</em></span></button>
  <button class="step cur"><span class="step-dot">2</span><span class="step-tx"><b>Dimension &amp; Details</b><em>In progress</em></span></button>
  <button class="step err"><span class="step-dot"><span class="ms" style="font-size:16px">priority_high</span></span><span class="step-tx"><b>Features</b><em>1 required left</em></span></button>
  <button class="step"><span class="step-dot">4</span><span class="step-tx"><b>Gallery &amp; Review</b><em>Optional</em></span></button>
</nav>
  • Current: red filled dot + soft red halo · bold label · red bar · caption In progress
  • Completed: green check dot · green bar · caption Completed
  • Needs attention: red-soft dot with ! · pale red bar · caption N required left
  • Not started: outline number · grey bar · caption Required / Optional
  • Steps sit 8px apart; the whole step is clickable
